AI that doesn't make things up

Answers come only from real stories.

  • Grounded only — the summary and chat see just this destination's published stories, treated as untrusted data.
  • Checked sources — every tip links to its source stories; the server rejects unknown or other-destination references.
  • No invented numbers — a price, time or distance must appear in the cited stories, or it's dropped.
  • No story? It says so — an answer citing no story becomes “the stories don't cover that yet”.
  • Honest failures — if Gemini is down, the summary says it will appear later and chat shows related stories.
  • Reliable — Gemini runs server-side with a rotating pool of up to ten API keys, a fallback model and cached summaries.

Trip-planning questions get a fixed, server-written note and a referral to The Visa Guy for full plans, visas or bookings.

Accounts, moderation & security

Safe by default.

Row Level Security

On every table. The public reads only published stories and visible comments.

Session identity

Comments and reactions use your own session. User IDs can't be supplied or faked.

Server-side secrets

Supabase and Gemini keys never reach the browser, logs or URLs.

Validated input

zod schemas, length limits, stripped control characters and rate limits.

Anonymous

Public pages never show emails or account IDs. User content renders as plain text.

Moderation

Email accounts via Supabase Auth. Moderators review AI-labelled submissions.

Getting started

Run it locally.

git clone https://github.com/shamil-tp/RegretMap.git
cd RegretMap
npm install
cp .env.example .env.local
npm run dev
  • Requirements — Node.js 24 and npm 11.19+.
  • Environment — Supabase URL and keys, Gemini key pool and model, moderator emails, site URL.
  • Database — run supabase/migrations in order, then the India and world seeds.
  • Auth — add <site>/auth/callback to Supabase redirect URLs.

Testing, CI & releases

Checked on every push.

npm ci→ lint→ type-check→ tests→ build

Design & credits

Design

A raw-paper canvas with a dot grid, black ink borders, hard block shadows, caution-yellow calls to action, regret red and map blue. Motion is CSS only and turns off for reduced-motion.

Known limitations

What's next.

  • Reporting — the Report button is a placeholder; moderators hide stories with SQL for now.
  • Accounts — no password reset or account deletion yet.
  • Rate limits — kept in memory per server instance (the submission cap is shared).
  • Not verified facts — stories are personal accounts. Always check official sources for permits, weather and safety.
